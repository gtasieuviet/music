Quản lý nhạc, lấy link trực tiếp cho SA-MP lưu trữ trên GitHub

Cách lấy link MP3 chuẩn trên GitHub:

1. Anh up file nhạc `.mp3` trực tiếp vào thư mục GitHub này (hoặc bấm nút Upload files).

2. Bấm vào file nhạc đó trên GitHub $\rightarrow$ Nhấn nút Download hoặc Raw $\rightarrow$ Copy đường dẫn URL.

3. Dán link đó vào khung bên dưới để thêm vào danh sách game.
